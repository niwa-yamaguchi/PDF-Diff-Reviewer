# PDF差分レビューア（PDF Diff Reviewer）

改訂前後のPDF図面を読み込み、変更箇所を色分けしてオーバーレイ表示するブラウザ内ツールです。設計変更レビューで大量の図面を目視照合する負担・見落としを減らすことを目的としています。

**公開URL: <https://pdfreview.goodsun-support.net/>** （Cloudflare Pages で公開中）

## 特徴

- **ラスタライズ→画素比較方式**でテキストレイヤに依存せず、ベクタPDF・スキャンPDFの双方で動作
- **図面比較**と**テキスト比較**の2つのモードを用途に応じて切り替え可能
- 処理はすべてブラウザ内で完結し、**ファイルを外部に送信しない**（アップロード・外部API・テレメトリなし）
- ViteとES Modulesで機能ごとに分割し、`dist/` へ静的配布物を生成

## モード

### 図面比較モード

新旧のPDFページをラスタライズし、画素単位で差分を検出して表示します。

- **差分表示**：削除・追加・共通を1枚に重ねてオーバーレイ
  - **赤＝削除（旧版のみ）／青＝追加（新版のみ）／グレー＝共通**
- **新旧切替表示**：旧版と新版を同一位置でパッと切り替えて目視比較（Spaceキーで切替）
- **左右表示**：旧版（左）と位置合わせ済み新版（右）を同時に表示
  - ズーム、パン、全体表示、1:1、ページ送りは左右で同期
  - 変更枠を両側へ常時表示し、枠の編集は差分表示へ戻って行う
  - 左右表示のPNGは現在ページ、PDFは全ページをフル解像度で横並びに保存
- **変更点を強調**：変更箇所を四角枠で囲って強調（ON/OFF切替）
- **変更枠の手編集**：自動検出した枠を手で直せる（「枠を編集」ボタン、または `E` キー）
  - 何も無い所をドラッグで枠を追加、枠をクリックで選択、内側のドラッグで移動、8つのハンドルでリサイズ、`Delete` で削除
  - `Ctrl+Z` で1手ずつ取り消し、「自動検出に戻す」で現在ページの手編集を破棄
  - 編集モード中のパンは `Space`+ドラッグまたは中ボタンドラッグ（ズームは従来どおりホイール）
  - 手編集した枠はページを送っても保持され、PNG／PDF書き出しにもそのまま反映される
  - DPI・しきい値・位置ズレ許容・位置合わせ・ページ整列など差分の前提が変わる操作を行うと、確認のうえ破棄される
- 解像度 DPI・インク判定しきい値の調整
- 差分の画素処理と自動位置合わせはWeb Workerで実行され、計算中も画面操作を受け付ける
  - 処理中にページを切り替えると、進行中の計算は打ち切られて新しいページの描画が始まる
- **位置ズレ許容（px）**：指定した画素数までの線のズレを差分とみなさず、再出力・スキャン由来のノイズを抑制
- **手動位置合わせ**：新版を上下左右に平行移動、**傾き補正**（0.1°刻み）、**拡大縮小**（0.1%刻み）
- **自動位置合わせ**：スキャン・再出力で生じる回転・拡大縮小・平行移動のズレを自動推定して補正（トグルでON/OFF、手動位置合わせと併用可）
  - 補正を採用するかは「実際に重ねたときインク画素がどれだけ一致したか」で判定し、改善しない場合は補正を適用しない
  - 推定結果（角度・倍率・移動量）と一致率はサイドバーに表示
- **向き（90°/180°/270°回転）の自動判定・手動補正**：改訂前後で用紙の向きが変わっているページも比較可能
  - 自動位置合わせONのとき、ページごとに新旧のインクの重なりを4通りの向きで実測し、最も一致する向きを自動選択（回転しない方が良ければ回転しない）
  - 判定が外れたページは、サイドバーの「向き（新版を90°回転）」ボタン（`↺ -90°`／`+90° ↻`）で新版だけをそのページ限定で手動回転でき、中央のボタンで手動指定を解除して自動判定に戻せる
  - 回転は画素の並べ替えのみで行うため画質は劣化しない
- **用紙サイズの自動合わせ**：A4とA3のように用紙寸法が異なるページ同士でも縮尺を揃えて重ね合わせ（用紙自体の縦横比が異なる場合は未適用。ただしA4縦↔A4横のように向きの違いで縦横比が入れ替わっているだけの場合は、向きの自動判定と組み合わせて適用される）
- **ページ整列**：改訂でページが追加・削除されて番号がずれた場合、片側に空白ページを挿入して以降を再整列（1手ずつ取り消し可／PDFを読み込み直すとリセット）
- ページ送り、ズーム／パン（全体表示・1:1）、現在ページのPNG保存・全ページのPDF保存
- 書き出したPNG／PDFには左上に凡例が入るため、ファイル単体でも色の意味が分かる（画面表示には入りません）
  - 差分表示のPNG・全ページPDFは「共通／削除／追加」。「変更枠」は枠の表示がONのときだけ加わる
  - 新旧切替表示のPNGは差分色を含まないため、枠の表示がONのとき「変更枠」1項目のみ。OFFなら凡例は入らない

### テキスト比較モード

pdf.js の `getTextContent()` でテキストを抽出し、行単位で差分をとってページ上にハイライト表示します（テキストレイヤを持つPDFが対象）。

- OLD／NEW を左右に並べて表示
- **赤＝削除／緑＝追加／黄＝変更** をページ上にハイライト
- ページ送り、ズーム、現在ページのPNG保存・全ページのPDF保存
- 書き出したPNG／PDFの上部ラベル帯に凡例（削除／追加／変更）が入る

## 使い方

1. 公開URLまたは開発サーバーをブラウザで開く
2. サイドバー上部で **図面比較** / **テキスト比較** を選択
3. 改訂前（OLD）・改訂後（NEW）のPDFをそれぞれ読み込む
4. **差分を表示** / **テキスト差分を表示** を押すと変更箇所が表示される
5. 図面比較でズレによる差分が目立つ場合は、**自動位置合わせ**をONにするか、**位置ズレ許容**・手動の位置合わせ（移動／傾き／拡大縮小）で調整する
6. ページの追加・削除で新旧のページ番号がずれている場合は、**ページ整列**で空白ページを挿入して対応づける
7. 自動検出の枠に過不足があれば、**枠を編集**で枠を足す・消す・動かす
8. ページを切り替えたり、モード・表示を切り替えながら確認する

## 依存

- [pdf.js](https://mozilla.github.io/pdf.js/) 3.11.174（Apache License 2.0）
- [jsPDF](https://github.com/parallax/jsPDF) 2.5.1（MIT License）
- [diff-match-patch](https://github.com/google/diff-match-patch) 1.0.5（Apache License 2.0）

依存ライブラリはnpmで完全一致のバージョンを固定しています。pdf.js Worker、CMap、標準フォントもビルド成果物へ同梱されるため、本番実行時のCDN接続は不要です。

## 開発

Node.js 22.12以上の22系を使用します。初回は依存を固定どおりに導入し、Vite開発サーバーを起動します。

```text
npm ci
npm run dev
```

テスト、ビルド、ビルド成果物の確認には次のコマンドを使います。

```text
npm run test
npm run test:e2e
npm run build
npm run preview
```

ソースは `src/app/`（組み立てと状態）、`src/features/`（画面機能）、`src/core/`（純粋計算）、`src/platform/`（ブラウザ基盤）、`src/workers/`（Web Workerの入口）へ分割しています。PDF、差分結果、ログは外部へ送信せず、処理はすべてブラウザ内で完結します。外部API、テレメトリ、実行時CDNは使用しません。

## 素材

## デプロイ

`npm run build` が生成する `dist/` を任意の静的ホストへ配置します。Cloudflare Pagesでは次の設定を使用します。

- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`

本番環境は Cloudflare Pages で <https://pdfreview.goodsun-support.net/> に公開しています。
